## 1. DT-1: topic test

### 1.1 Design rule (revised at Phase 2 review, 1 Oct 2026)

> **No existing topic earns a standalone lesson by default. A topic receives deliberate instructional time only where recruits require knowledge, a model or a tool before they can meaningfully practise or apply the associated behaviour.**

A topic can need **deliberate instruction** without needing a **standalone lesson**. That instruction can be a short, explicit input placed inside an activity or debrief.

**The test question for every topic:** *Before a recruit can practise or apply this behaviour, do they need to be taught something first?*

- If yes, it gets explicit instruction, sized to what is needed.
- If no, it is learned through activity, debrief, lens or reference.

### 1.2 Treatments

Each topic gets one or more of these treatments:

| Code | Treatment | Meaning |
|---|---|---|
| **EI** | Explicit instruction | Deliberate, short teaching of knowledge, a model or a tool. Not necessarily a standalone lesson |
| **ACT** | Activity | Learned by doing a task |
| **EMB** | Embedded concept / tool | Introduced and used inside an activity, without a separate input |
| **DQ** | Debrief question | Arises as a question after an experience |
| **LENS** | Developmental lens | A recurring way of looking at behaviour (Section Commander language, self-check) |
| **REF** | Reference | Available in the workbook reference section; not taught |
| **REM** | Remove | Proposed for removal |

`Where`: D1 = Day 1; D2 = Day 2; P2 = Part 2 / rest of TAD; Ex = Ex One/Two; Ref = reference.
