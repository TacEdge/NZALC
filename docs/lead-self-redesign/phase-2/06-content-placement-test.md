# 06 — Content Placement Test

*DT-1 (the topic test) and ST-3 (the experience test) applied to the existing workbook. Component IDs are from Phase 1 doc 01. Phase 1 KEEP/MODIFY verdicts were inputs, not conclusions.*

## 1. DT-1: topic test

For each existing subject:

- **Role**: concept, tool, lens, activity, prompt or reference.
- **Where**: Day 1 (D1), Day 2 (D2), Part 2 (P2), Reference (Ref).
- **Classroom time?** **Yes** = a dedicated input block; **Embedded** = taught inside an activity or debrief; **No** = prompt or reference only.

### Summary: what needs classroom time

| Classroom time | Subjects |
|---|---|
| **Yes** (short dedicated input) | Value Adds; Identity vs Reputation; Comfort Zone; Feedback/DEB/DESC; P = P – I; mental skills (subset) |
| **Embedded** in activities and debriefs | Leadership definition; Ethos & Values; Above/Below the Line; Trust; SA levels; WAFOS; Teams; Intent; synchronisation/RRR; section culture; circle of concern; resilience framing; SSR |
| **No** (reference or prompt) | LDS/Tōtara/Growth Rings; Framework table; Conflict; frame of reference; decision models; risk matrix; followership/functional leadership; Schein; Change; mental-health continuum detail |
| **Remove** | Instruction Styles; repeated Lesson Reflection pages; repeated Value Add text |

Of the eleven current topic chapters, **only Lead Self Development (identity, comfort zone, feedback) and Resilience (P = P – I, mental skills) need dedicated input**. The rest contribute as activities, lenses or reference.
